# SaberLAB

Aplicación educativa que funciona **sin conexión a Internet**, pensada para reducir la brecha digital entre estudiantes de zonas rurales y urbanas. Cada colegio la adapta a sus grados y asignaturas: el docente crea y organiza el material, y el estudiante lo consulta desde su dispositivo, aunque no tenga señal.

Proyecto de grado 11-2, área de Programación de Software, Institución Educativa Santa Teresa de Pachaquiaro (IESTAP), Puerto López, Meta.

## Objetivo

Desarrollar una aplicación educativa que funcione sin conexión a Internet, para facilitar el aprendizaje de quienes no cuentan con conexión, mediante contenidos y actividades educativas accesibles.

## Roles y casos de uso

| Rol | Casos de uso |
|---|---|
| Docente | Crear material educativo; organizar contenido por asignatura |
| Estudiante | Buscar material por asignatura; acceder al material sin Internet |
| Administrador | Administrar el acceso a cuentas y vigilar el almacenamiento |

## Tecnología

- **MIT App Inventor** para construir la aplicación Android.
- **Almacenamiento local** en el dispositivo: el material, las cuentas y el avance de lectura no dependen de servidores externos.

## Página web del proyecto

El archivo `index.html` es la página que explica el proyecto. No necesita instalación: se abre en cualquier navegador.

Para publicarla gratis con GitHub Pages: en el repositorio ir a **Settings → Pages**, en *Source* elegir la rama `main` y la carpeta `/ (root)`, y guardar. En unos minutos queda disponible en `https://gab-bi22.github.io/SaberLAB/`.
